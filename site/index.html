Get started

Up and running in three steps

Pick how you want to run WireWise. All three are free.

Windows installer

  1. 1

    Download

    Choose Download for Windows at the top of the page. The file is named like this, and its size shows under the button.Open this page on your Windows PC and choose Download for Windows.

    WireWise-Setup-x.y.z.exe
  2. 2

    Run the installer

    Open the file and follow the prompts. If SmartScreen shows “Windows protected your PC”, choose More info, then Run anyway.

  3. 3

    Launch and stay current

    Open WireWise from the Start menu. It tells you when a new version is out. Download it when it suits you, then restart to update.

SmartScreen may ask first. Windows warns about apps it has not seen often. WireWise is open source, so you can read the code and releases on GitHub before you run it.

Portable

  1. 1

    Download

    Choose Portable under the main button. It is a single program file, so there is nothing to unpack.

    WireWise-Portable-x.y.z.exe
  2. 2

    Run it from anywhere

    Put it on your desktop or a USB drive and double-click. It needs no installation and no administrator rights.

  3. 3

    Update when you like

    To update, download the latest Portable file and use it in place of the old one. The update button inside the app installs the full version instead.

No admin rights needed. The portable file does not touch system folders. Delete the file to remove the app; saved settings stay in your Windows user folder.

In your browser

  1. 1

    Open the app

    Choose Open in browser. WireWise runs in a desktop or tablet browser with nothing to install.

    app/
  2. 2

    Pick your code standard

    The first-time guide opens on your first visit. Start by choosing PEC 2017 or IEC 60364 in the overflow menu.

  3. 3

    Work offline

    Prefer a file? In the app, open the File menu and choose Save standalone HTML. Open that file from your disk any time, with no connection.

    your_project_PEC.html

Phones open view-only. The browser app is for desktop and tablet. On a phone you can open shared circuits and look around, but not edit.
